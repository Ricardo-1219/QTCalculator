## 一、功能概述

一个可以使用**鼠标**或**键盘**操作的计算器，支持：

- 四则运算：加、减、乘、除，支持连续运算；
- 小数输入：同一个操作数只允许一个小数点，直接按 `.` 会补前导 0；
- 退格（⌫）、清除当前操作数（CE）、全部清除（C）；
- 正负号（±）、百分比（%）、倒数（1/x）、平方（x²）、开平方（√）；
- 异常输入处理：连续小数点、连续运算符、除以 0、负数开平方、结果之后继续输入等；
- 鼠标与键盘走**同一套处理逻辑**（见 `Calculator::dispatch`）。

## 三、编译与运行

命令行（Qt 6 + MinGW）：

```bat

qmake ..\Calculator.pro
mingw32-make
release\Calculator.exe
```

也可以直接用 Qt Creator 打开 `Calculator.pro`，选择 Desktop Qt 6.x MinGW 套件后点击“运行”。

## 四、界面设计

- 上方是显示区：`labExpression`（QLabel，显示算式/预览，灰色小字）、`editDisplay`（QLineEdit，显示当前输入或结果，大号右对齐，只读）。
- 下方是按键区：`buttonPanel` 中用一个 **QGridLayout**（6 行 4 列）排布 24 个 `QPushButton`，
  与 Windows 计算器的排布一致：`% CE C ⌫ / 1/x x² √ ÷ / 789× / 456− / 123+ / ±0.=`。
- 所有按钮的 `focusPolicy` 保持默认，显示控件的 `focusPolicy` 设为 `NoFocus`，
  这样键盘输入不会被输入框吃掉，而是交给主窗口的 `keyPressEvent` 统一处理。

## 五、计算状态管理

程序用 5 个成员变量描述计算器的全部状态：

| 变量 | 含义 |
| --- | --- |
| `m_firstOperand` | 第一个操作数 |
| `m_pendingOp` | 待执行的运算符（None/Add/Sub/Mul/Div） |
| `m_entry` | 当前正在输入的操作数（**用字符串保存**，方便处理小数点与退格） |
| `m_startNewEntry` | 下一次输入数字时是否要开始新的操作数 |
| `m_showingResult` | 当前显示的是否是计算结果 |
| `m_error` | 是否处于错误状态（如除以 0） |

关键规则：

1. 按运算符时，如果已经有待执行的运算符且用户已经输入了第二个操作数，就**先算出中间结果**再继续，实现连续运算；
2. 如果刚按过运算符又按了另一个运算符，只**替换运算符**，第一个操作数不变（处理“连续操作符”）；
3. 按 `=` 后 `m_pendingOp` 清空、`m_showingResult` 置真，此时再输数字会开始一轮新计算（处理“结果之后继续输入”）；
4. 出错后只响应 `C`/`CE`，其它按键一律忽略，避免用非法值继续计算。

## 六、鼠标与键盘复用同一套逻辑

- 24 个按钮全部连接到同一个槽 `Calculator::onButtonClicked()`，由按钮文字翻译成“输入记号”
  （`Calculator::buttonToken`），再调用 `Calculator::dispatch()`。
- `keyPressEvent()` 把键盘按键也翻译成**同样的输入记号**，同样调用 `dispatch()`。

也就是说，无论鼠标还是键盘，最终都进入 `dispatch()` 这一条路径，逻辑只有一份。

| 键盘按键 | 等价操作 |
| --- | --- |
| `0`~`9` | 数字键 |
| `.` | 小数点 |
| `+` `-` `*` `/` | 加 减 乘 除 |
| `Enter` / `Return` / `=` | 等号 |
| `Backspace` | 退格 ⌫ |
| `Delete` | CE（清除当前操作数） |
| `Esc` | C（全部清除） |
| `%` | 百分比 |

## 七、异常与边界处理

| 测试输入 | 期望现象 | 处理方式 |
| --- | --- | --- |
| `1.2.3` | 显示 `1.23` | `inputDot()` 判断当前操作数已含小数点就忽略 |
| `5 + × 3 =` | 显示 `15` | `applyOperator()` 在“刚按过运算符”时只替换运算符 |
| `5 ÷ 0 =` | 显示“除数不能为 0” | `compute()` 中除数为 0 时调用 `showError()` |
| `√`（负数） | 显示“负数不能开平方” | `applyUnary()` 中判断 |
| `8 + 2 =` 再按 `5` | 显示 `5`（开始新计算） | `inputDigit()` 判断 `m_showingResult` |
| `2 + 3 × 4 =` | 显示 `20`（左到右连续运算） | `applyOperator()` 中先结算前一组运算 |
| 结果状态下按退格 | 显示不变 | `backspace()` 在结果/新操作数状态下直接返回 |
